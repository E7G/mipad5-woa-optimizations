# 现场验证摘要（截至 2026-10-18）

一个 nabu，Windows 11 Enterprise 25H2 ARM64（26200.9711）。不是多设备覆盖测试。

## 触摸

- 点按、滑动、多指缩放、手动熄屏/唤醒验证通过。
- 一次约 719 秒熄屏 ETW，去除头尾各 2 秒后 SPI/SP19 active/idle 回调均为 0；不是物理中断或电流测量。
- 同期 SW/HW DRIPS 仍为 0%。
- 主机 power mock：10,000 个显示循环及 D0/失败/锁顺序/定时器排空断言。
- 主机 firmware mock：两份真实输入的逐步失败注入与清理检查、50,000 个确定性变异/截断解析用例曾通过。真实固件不在公开仓库。

## GRAPHICS

- 微型硬件 D3D11 绘制/读回：12 次绘制、53,248 像素含对照，误差 0，DeviceRemovedReason=0。不是性能评分。
- GPU GRAPHICS 与 MMU1 空闲 F1；显示原配置保留。成功熄屏/恢复至同次启动的原桌面，触摸正常。
- 约 103.76 分钟熄屏；系统睡眠段容量 28694→28325→27787，满容量原始值 33600。合计约 2.70%，按睡眠时长折算约 1.56%/小时。电池计量估算，无匹配对照，不宣称优化收益。
- 目标电源/图形 ETW 解析错误 0、丢失事件 0。7 个 ETL 头部解析错误单列，不混作驱动事件。
- 所查 System 41/1001/4101/6008 窗口没有新增记录；不是穷尽所有错误的证明。
- **整机 DRIPS 0%，其他组件仍 F0；长期稳定和完整待机修复未完成。**

## 未完成/失败项

- VIDEO：仅 D3D11VideoDevice 枚举到 9 个解码配置，没有实际解码/断电恢复验证，没有写入该项电源配置。
- 全局 ForceActive=0：曾导致黑屏/无法唤醒，已回滚。
- 错误名称 GRAPHICS_POWER_STATES 注册表项：未观察到效果，已删除；不要照抄。
- PEP、TrEE、RTC、虚拟化等历史排查不作为本仓库已修复功能。未发布供应商二进制补丁。

## 复测建议

先保存基线和回滚，再分别测亮屏、硬件绘制/视频、手动睡眠及触摸；始终区分“软件 F-state”“实际耗电”“恢复可靠性”。隔离单变量，不重复全局黑屏试验。原始 ETL、转储、注册表备份和网络/设备身份不公开。
